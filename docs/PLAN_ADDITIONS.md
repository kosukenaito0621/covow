# 追加の計画（2026-10-25）

チェックポイント2でデザインが承認されたあとに追加された要望と、その進め方。`PHASE0_PLAN.md` と `DESIGN_DECISIONS.md` より、こちらを優先する。

## 1. 決まったこと

| 項目 | 決定 |
|---|---|
| 人数 | 1つのスペースに **1〜4人**（一人でも、ペアでも、グループでも使える） |
| スペースの数 | **1人1つ**（指示書 v1 どおり） |
| 言語 | **英語／日本語**。最初は**端末の言語に合わせる**（日本語の端末なら日本語）。設定でいつでも切り替え |
| テーマと言語の保存先 | **アカウントに保存**（どの端末でも同じ）。ログイン前の画面は端末の言語で表示 |
| テーマ | Aurora・Earthy・Tropical・Dusk・Sakura・Frost の6種（`DESIGN_DECISIONS.md`） |

## 2. 一人・ペア・グループ（1〜4人）

- スペースは作った時点では自分1人。招待しなければ一人用として使える。
- DB の2人上限のトリガーを **4人上限** に変える（マイグレーションを追加。まだ本番 DB はないので既存データへの影響はない）。
- 招待リンクは、4人未満のあいだ発行できる。4人そろったら参加を断る。
- 「購入担当者」は「自分／メンバーの誰か1人／みんな」から選ぶ（`assignee_user_id`、NULL＝みんな）。
- 分析の「ふたり」タブは **MEMBERS**（メンバー別）にする。一人のときは表示しない。
- 文言は人数に合わせる（例：一人のときは「招待する」を控えめに）。

## 3. 英語／日本語（i18n）

- 外部の重いライブラリは使わず、型付きの辞書（`src/shared/i18n/en.ts`・`ja.ts`）と `useT()` で切り替える。辞書の抜けは型チェックで見つかるようにする。
- 金額は言語に関係なく円（`Intl.NumberFormat(locale, { currency: 'JPY' })`）。日付の表記は言語に合わせる（例：Oct 27／10月27日）。
- API のエラーはコード（例：`ALREADY_PURCHASED`）を返し、画面で言語に合わせた文に直す。
- `users` に `locale`（`en` / `ja`）と `theme` を追加する。

## 4. 体験版（ログインせずに試す）

これまでに作ったアプリ（献立アプリ・MIGAKU・Planty）と同じ考え方にする。

- 「ログインせずに試す」（または `/login?try=1`）で、**24時間だけ使える仮のアカウント**と、**数か月使い込んだ見本のスペース**を作る（予算・支出・購入予定の履歴、メンバー役の「Haru／はる」さん）。
- 画面の上に `DEMO` と残り時間、「Googleで始める」を出す。
- 招待・アカウント削除など、外に影響する操作はお休みにする。
- 期限が過ぎたら、毎日の定期処理（Workers の Cron Trigger）でスペースごと消す。作れる回数は IP ごと・1日ごとに上限を設ける。
- 見本のデータは架空のもの。本番の実データは使わない。

## 5. 伴走型の初回説明（やってみよう）

献立アプリ・MIGAKU・Planty の「やってみよう」と同じ作り。

- 画面の下（ナビの上）に**コーチ**が出て、ミッションを1つずつ案内する。「やってみる」でその画面へ移り、**押す場所を光る枠で囲んで**一言添える（まわりは暗くせず、ふだんどおり操作できる）。
- **実際にその操作をすると自動でクリア**になり、「クリア！次は…」へ。文字の入力が要るところは見本の文字を入れておく。
- 進み具合は端末に保存する。ぜんぶ終えたら一度だけお祝いを出す。一覧から好きなミッションも選べる。
- 体験版では最初から表示する。**はじめてログインした人**には、初期設定の前に「使い方を体験する（約3分）」と「すぐに設定をはじめる」を選んでもらう。

ミッション（案）：

| # | ミッション | 光らせる場所 |
|---|---|---|
| 1 | 買いたいものを登録してみよう | 「＋」→ 見本入りのシートで登録 |
| 2 | 購入済みにしてみよう | 予定の詳細 →「購入済みにする」→ 実際の金額を確認 |
| 3 | 予定なしの支出を記録してみよう | 支出一覧 → 追加 |
| 4 | 今週の支出を見てみよう | 曜日のチップ（見るだけ） |
| 5 | 予算を決めてみよう | 設定 → 月間予算（USED が満ちていく） |
| 6 | 分析を切り替えてみよう | 分析のタブ |
| 7 | 一緒に使ってみよう | 「メンバー役を呼ぶ」→ Haru さんが予定を追加しに来る |
| 8 | テーマを変えてみよう | 設定 → テーマ |

## 6. 初期設定（はじめてログインした人）

1. 表示名
2. 使い方：**ひとりで**／**誰かと一緒に**（一緒にの場合は「スペースを作る」か「招待リンクで参加」）
3. 今月の予算（スキップ可）
4. 最初の購入予定（スキップ可）
5. 誰かと一緒の場合だけ：招待リンクを送る（あとでも可）
